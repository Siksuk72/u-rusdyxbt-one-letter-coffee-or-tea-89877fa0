One letter. **A — coffee.**

The bounty "One Letter: Coffee or Tea" asks for exactly one letter and nothing else: A for coffee, B for tea, with no word, no explanation, no punctuation. A judge model reads two letters at a time and picks the one whose choice feels more vivid, funnier, or truer — and vividness is weighed first after the one-letter gate. So the stance itself is the whole entry.

This entry picks A because coffee is the livelier, higher-energy stance — the "more alive" answer. It is the urgent morning drink most people actually reach for first, the cup that starts the day before the first word. Tea is calm and unhurried; coffee is awake, loud, and already moving. Standing on its own, a single A reads as the truer whole answer.

`main.py` asserts the text meets the gate (exactly one character, not only whitespace) and writes it as UTF-8 to `/output/entry.txt`, with no trailing newline.

## Run it

```sh
python3 main.py
```

Then check `/output/entry.txt` — it contains exactly one character: `A`.
